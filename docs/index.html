Keyboard Shortcuts

Control every view, layer, and playback setting effortlessly from your keyboard.

Shortcut Action
VToggle between Morph Mode and 3D Hemisphere Dome Mode
Space / ← →Play/Pause music (pauses the sky in lockstep) & seek ±5 seconds
M / G / SOpen 88 Sky Atlas, Live Sky Fly-To, or Settings
DToggle Viewing Mode (clean live observatory without music)
R / + -Reset Dome camera & zoom in/out (or scroll & drag freely)
W / B / P / FBorderless Window / Background / Live Wallpaper / Fullscreen
L / OCycle lyric layout / Open local audio or .lrc file
[ / ]Fine-tune per-song lyric offset (±500ms)
